# STALCRAFT Auction Bot

Telegram-бот, который следит за аукционом STALCRAFT через официальный API и рассылает подписчикам уведомления о дешёвых лотах.

Сейчас отслеживается один предмет — «Продвинутые запчасти» (ID `y3nmw`), ID зашит в `main.py`.

## Что делает бот

- Раз в цикл опрашивает аукцион STALCRAFT: до 200 лотов, отсортированных по цене выкупа (от дешёвых к дорогим).
- Выбирает лоты, у которых цена выкупа **за штуку** не выше порога `PRICE_LIMIT`. Лоты без выкупа (только ставки) пропускаются.
- Отправляет найденные лоты всем подписчикам в Telegram. Если есть картинка `y3nmw.png`, она отправляется вместе с подписью, иначе уходит только текст.

## Как это работает

- **Опрос (polling).** Бот в бесконечном цикле делает две вещи: сначала читает новые сообщения боту через `getUpdates`, затем запрашивает аукцион. Между итерациями пауза 10 секунд, чтобы не перегружать API.
- **Подписчики.** Список хранится в `subscribers.json` рядом со скриптом и переживает перезапуски. Стартовый подписчик — `TG_CHAT_ID`. Любой пользователь, который написал боту (например, `/start`), автоматически добавляется в рассылку и получает подтверждение. Если пользователь заблокировал бота (ответ 403), он удаляется из списка.
- **Порог цены.** Цена за штуку = `buyoutPrice / amount`. В уведомление попадают лоты с ценой ≤ `PRICE_LIMIT`.
- **Защита от повторов.** Уже отправленные лоты запоминаются по ключу (количество, цена выкупа, время начала и окончания). Список хранится в памяти и сбрасывается при перезапуске бота или когда он превышает 5000 записей.
- **Картинки.** Файл `<ID предмета>.png` рядом со скриптом отправляется как фото с подписью. Подпись Telegram ограничена 1024 символами: если список длиннее, фото уходит с первой строкой в подписи, а полный список — отдельным сообщением. Длинный текст разбивается на части по ~4000 символов.
- **Ошибки.** Сетевые ошибки и ответы API с кодом не 200 пишутся в консоль, бот продолжает работу.

## Настройка (.env)

Настройки читаются из файла `.env` в папке проекта. Шаблон — `.env.example`. Скопируйте его в `.env` и заполните значения.

| Переменная | Обязательна | Описание |
|---|---|---|
| `TG_BOT_TOKEN` | да | Токен Telegram-бота. Выдаёт @BotFather. |
| `TG_CHAT_ID` | да | ID Telegram-чата, который становится первым подписчиком рассылки. Узнать свой ID можно у @userinfobot. |
| `SC_CLIENT_ID` | да | Client-Id приложения EXBO для доступа к API STALCRAFT. |
| `SC_CLIENT_SECRET` | да | Client-Secret приложения EXBO. |
| `REGION` | нет, по умолчанию `eu` | Регион игры: `ru`, `eu`, `na` или `sea`. |
| `PRICE_LIMIT` | нет, по умолчанию `50000` | Порог цены за штуку в игровой валюте. Лоты дороже не отправляются. |

Если обязательные переменные из первых четырёх строк не заполнены, бот выводит сообщение об ошибке и завершается.

## Быстрый старт

Нужен Python 3.

```bash
cd stalcraft-bot
python3 -m venv venv
venv/bin/pip install -r requirements.txt
cp .env.example .env      # затем заполните .env своими значениями
venv/bin/python main.py
```

В Windows вместо `venv/bin/...` используйте `venv\Scripts\...`.

Зависимости из `requirements.txt`: `requests` и `python-dotenv`.

Файл `bot.py` — вспомогательный скрипт: он один раз запрашивает 10 самых дешёвых лотов и выводит их в консоль. Удобно для проверки API и настроек.

## Автозапуск на Raspberry Pi

Настройка автозапуска через systemd (сервис `stalcraft-bot.service`), копирование файлов и обновление бота описаны в [DEPLOY.md](DEPLOY.md).

## Безопасность

Все секреты (токен бота, `SC_CLIENT_SECRET`, `TG_CHAT_ID`) хранятся только в файле `.env`. Не добавляйте их в код и не публикуйте `.env` в репозитории. Если токен бота утёк, перевыпустите его у @BotFather (команда «Revoke current token») и обновите `.env`.
